## 자료 오류 의심 (출제 원칙: 이 항목을 정답 근거로 쓰지 않는다)
명백한 오기·오류는 **과학적으로 맞는 쪽을 정답**으로 하고 해설에 "자료 표기와 다름"을 적는다.
용어 선택(예: ΔG<0 을 "발열"로 부르는 번역)은 자료 표현을 따른다.

| 위치 | 자료 표기 | 판단 |
|---|---|---|
| 1강 2-(3) | 원자량 = 중성자 수 + 양성자 수 | 그 정의는 질량수. 원자량은 동위원소 평균이라 정수가 아니다 — 출제 시 "질량수"로만 묻는다 |
| 1강 6-(3) | 수소이온(H-) | H⁺ 오기 |
| 1강 표 | Cl: 소화작용 및 광합성의 HCl | 광합성과 HCl 은 무관 — 출제 제외 |
| 2강 5-(1) | 폴리펩티드: 20개의 아미노산이 … 연결 | "20종"의 뜻. 개수로 묻지 않는다 |
| 2강 5-(2) | 겸상적혈구: 글루타민 → 발린 | 글루탐산 → 발린이 맞다 |
| 2강 6-(2) | 전령RNA(tRNA) 에서 자기 상보 염기쌍 | 자기 염기쌍을 이루는 대표는 tRNA(운반RNA). "전령"은 오기 |
| 5강 열역학 | 생명체 엔트로피 감소 … "1법칙을 따르게 된다" | 주변 엔트로피 증가로 우주 엔트로피가 늘어나는 것은 2법칙 |
| 5강 효소억제 | 경쟁적 억제 예로 공유결합 비가역 독극물 | 비가역 억제는 경쟁적 억제와 별개 범주 — 경쟁적 억제의 예로 묻지 않는다 |
| 4강 능동수송 | Na⁺-K⁺ 펌프를 1·2차 구분 없이 역방향 예로 | 역방향수송 예로만 묻고 1/2차 구분엔 쓰지 않는다 |
