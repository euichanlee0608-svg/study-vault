## 오리엔테이션에서 새로 강조된 개념 (기존 문제은행에 없음 → 보강 대상)
1. **집중소자(lumped element) 가정** — 모든 전자기 현상은 맥스웰 방정식이지만, 회로 크기가 신호 파장보다 충분히 작을 때만
   에너지를 C(전기)·L(자기)·R(소산)에 몰아 둔 회로이론으로 대체할 수 있다. 조건: 회로 치수 ≪ 파장.
2. **접지 3종 구분** — 신호 접지(전위 기준으로 정한 도체, 대지 연결 의미 아님) · 대지 접지(땅에 박은 금속) ·
   섀시 접지(금속 케이스, 안전 때문에 보통 대지에 연결). 교재 기호는 이 구분을 안 하므로 문맥으로 읽어야 하고 대개 신호 접지다.
3. **그라운드 루프는 잡음원** — 서로 다른 접지를 생각 없이 잇지 말 것.
4. **자동차 차체 귀환(earth-return) 방식** — 전선 한 가닥으로 공급하고 금속 차체를 귀환로로 쓴다(음극 접지).
5. **실습 도구** — 전원장치 사용, 브레드보드는 시험용이지 영구 회로용이 아님, 아두이노 제어보드,
   제작 흐름 회로도 → 레이아웃 → 거버 파일 → PCB → 납땜 → 시험.
