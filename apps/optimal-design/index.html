0-1. 최적설계란

0-4. 국소 최적해 vs 전역 최적해

  │   ╱  ╲      ╭─╮
  │  ╱    ╲    ╱   ╲

  • 국소 최적해 (Local Optimum): 주변보다는 좋지만 더 좋은 데가 딴 데 있음
  • 전역 최적해 (Global Optimum): 진짜 제일 좋은 곳
  • 볼록(Convex) 문제면 국소 = 전역이 보장됩니다. 하지만 실제 구조해석 문제는 거의 다 비볼록이라 시작점에 따라 다른 답이 나옵니다.

경사 기반 알고리즘(SQP, MFD)이 "시작점에 민감하다"는 말이 이 뜻입니다. 언덕을 내려가다 보면 가장 가까운 골짜기에 갇힙니다.

1. 최적화 문제의 수학적 정의

1-1. 표준형

    minimize    f(x)                    ← 목적함수
    subject to  gⱼ(x) ≤ 0    j = 1..m   ← 부등식 제약
                hₖ(x) = 0    k = 1..p   ← 등식 제약
                xᴸ ≤ x ≤ xᵁ             ← 변수 상하한 (side constraint)
  • 최대화는 max f(x) = min −f(x) 로 바꿔서 같은 틀로 풉니다.
  • 제약은 ≤ 0 형태로 정규화합니다. 예: Max_Disp ≤ 1.5 → g(x) = Max_Disp(x) − 1.5 ≤ 0

Arm 모델 문제를 표준형으로 쓰면:

    minimize    Volume(x)
    subject to  Max_Disp(x) − 1.5 ≤ 0
                x = [length_1..5, radius_1..3, height]
                각 변수의 상하한 지정

1-2. KKT 조건 (최적해의 필요조건)

제약이 있는 문제에서 점 x*가 최적해이려면 다음을 만족해야 합니다 (Karush-Kuhn-Tucker 조건):

① 정상성    ∇f(x*) + Σ λⱼ ∇gⱼ(x*) + Σ μₖ ∇hₖ(x*) = 0
② 실행가능성  gⱼ(x*) ≤ 0 ,  hₖ(x*) = 0
③ 쌍대 실행가능성  λⱼ ≥ 0
④ 상보 여유조건   λⱼ · gⱼ(x*) = 0

④가 실무적으로 중요합니다. λⱼ · gⱼ = 0 이라는 건: - 제약이 활성(active) 이면 (gⱼ = 0, 경계에 붙음) → λⱼ > 0 가능 - 제약이 비활성이면 (gⱼ < 0, 여유 있음) → λⱼ = 0

즉 최적해에서는 제약이 경계에 딱 붙거나(active), 아예 무관하거나 둘 중 하나입니다. Arm 모델에서 최적해의 Max_Disp가 전부 1.500~1.507로 나오는 이유가 이것입니다. 제약이 active하게 걸린 것이죠.

λ (라그랑주 승수)의 물리적 의미: 제약을 1단위 완화했을 때 목적함수가 얼마나 개선되는지를 나타냅니다. "그림자 가격(shadow price)"이라고도 합니다. Max_Disp 제약을 1.5→1.6으로 늘리면 Volume이 얼마나 더 줄어드는가, 같은 이야기.

1-3. 왜 그냥 다 계산해보면 안 되나

설계변수 9개를 각 10단계씩만 훑어도 10⁹ = 10억 번 해석입니다. 1회 4초면 127년. 그래서 똑똑하게 적은 횟수로 찾는 알고리즘이 필요합니다.

이게 최적설계 전체 워크플로가 존재하는 이유입니다:

DOE로 적게 뽑아보고 → 중요 변수만 남기고 → 대리모델로 싸게 근사하고
→ 알고리즘으로 효율적으로 탐색 → 마지막에 진짜 해석으로 검증

2. "확률론적"의 두 가지 뜻 ★

이 단어가 헷갈리는 가장 큰 이유는 완전히 다른 두 개념에 같은 말을 쓰기 때문입니다. 보고서에서 이 둘을 섞으면 바로 틀린 문장이 됩니다.

축 질문 용어 예시
축 A — 알고리즘의 재현성 같은 입력으로 두 번 돌리면 같은 답이 나오는가? 결정론적 알고리즘 ↔ 확률적(stochastic) 알고리즘 ARSM은 매번 같음 / GA는 매번 다름
축 B — 문제의 형식 설계변수·물성에 산포(불확실성) 를 넣는가? 결정론적 설계(DDO) ↔ 확률론적 설계(RBDO) "치수 = 10mm" / "치수 ~ N(10, 0.1²)"

두 축은 독립입니다.

   축   결정론적    ARSM, SQP, MFD     SORA, SORA_ARSM

   :  ────────────────────────────────────────────────
   알   확률적      GRSM, GA, MOGA     GA + Monte Carlo

축 A: 알고리즘이 확률적이라는 뜻

내부에 난수(random number) 를 쓴다는 뜻입니다. - GA는 초기 개체군을 무작위로 만들고, 교차·변이 지점도 무작위로 고릅니다 - GRSM은 전역 탐색 단계에서 무작위 샘플링을 합니다 - → 시드가 고정되지 않으면 실행할 때마다 다른 답이 나옵니다

이것은 결함이 아니라 정상 동작입니다. 전역탐색을 하려면 무작위성이 필요합니다. 대신 보고할 때 "N회 반복해서 평균 ± 표준편차" 형태로 써야 합니다.

축 B: 문제가 확률론적이라는 뜻

설계변수나 물성이 확정값이 아니라 분포라는 뜻입니다. - 도면에 10mm라고 써도 실제 생산품은 9.95~10.05mm로 흩어집니다 - 강판 항복강도도 로트마다 다릅니다 - → 이 산포를 확률분포로 모델링하고, 제약을 확률로 표현합니다

DDO:   Max_Disp ≤ 1.5              (확정)
RBDO:  P(Max_Disp ≤ 1.5) ≥ 0.95    (95% 확률로 만족)

면접·보고 팁: "GA는 확률론적 최적화입니다"는 애매한 표현입니다. "GA는 확률적 알고리즘입니다(축A). 확률론적 설계인 RBDO와는 다른 개념입니다" 라고 하면 정확합니다.

4. DOE — 실험계획법

4-1. 왜 필요한가

해석 1회가 비싸므로 최소 횟수로 최대 정보를 얻어야 합니다. DOE는 "어떤 설계점들을 골라 해석할 것인가"를 통계적으로 설계하는 기법입니다.

목적은 크게 둘입니다: 1. 스크리닝 — 어느 변수가 중요한지 골라내기 (§6) 2. 대리모델 학습 데이터 생성 — 응답면을 만들 재료 (§5)

이 둘은 요구하는 DOE가 다릅니다. 스크리닝은 격자형(요인배치), 대리모델은 공간충전형이 유리합니다.

4-2. 코딩 (Coding)

변수마다 단위와 범위가 다르므로 [-1, +1]로 정규화해서 다룹니다.

x_coded = 2·(x − x_min)/(x_max − x_min) − 1

length_1이 [-0.5, 2.0] 범위면 -0.5 → -1, 2.0 → +1 로 매핑됩니다. 이렇게 해야 서로 다른 변수의 효과 크기를 공정하게 비교할 수 있습니다.

4-3. 주효과와 교호작용

주효과 (Main Effect) — 변수 하나를 낮은 수준에서 높은 수준으로 바꿨을 때 응답의 평균 변화량:

E_j = ȳ(x_j = +1) − ȳ(x_j = −1)

교호작용 (Interaction) — 두 변수가 함께 작용할 때 생기는 추가 효과. "A의 효과가 B의 수준에 따라 달라진다"는 뜻입니다.

E_jk = ½ [ ȳ(x_j·x_k = +1) − ȳ(x_j·x_k = −1) ]

예시: 리브 두께를 늘리면 강성이 오르는데, 그 효과가 리브 높이에 따라 달라진다면 두께×높이 교호작용이 있는 것입니다.

직교 설계(orthogonal design) 에서는 주효과와 교호작용이 서로 완전히 분리됩니다. Full Factorial이 그렇습니다. 이게 Full Factorial의 가장 큰 장점입니다.

4-4. Aliasing과 Resolution

Fractional Factorial은 조합의 일부만 돌리므로, 어떤 효과들이 서로 구분 불가하게 섞입니다. 이걸 aliasing(별칭)이라고 합니다.

Resolution 섞이는 정도 의미
III 주효과 ↔ 2차 교호작용 가장 경제적. 주효과가 교호작용과 섞여 있어 위험
IV 2차 교호작용끼리 주효과는 깨끗함. 교호작용끼리는 구분 불가
V 2차 ↔ 3차 교호작용 주효과·2차 교호작용 모두 깨끗함

실무 기준: 스크리닝만이면 III로 충분, 교호작용까지 봐야 하면 IV 이상.

4-6. 결정론/확률론 관점

  • [축A] 격자형(Full/Fractional Factorial, PB, Taguchi, CCD, Box-Behnken)은 완전 결정론적 — 설계점이 수식으로 정해져 매번 동일
  • [축A] MELS·Sobol·Hammersley·LHS는 준난수(quasi-random) — 시드/오프셋이 같으면 재현됨. Fill Random만 진짜 무작위
  • [축B] DOE 자체는 산포 개념이 없음. 다만 HyperStudy는 Uncontrolled(노이즈) 변수를 별도 축으로 둘 수 있어 확률론적 DOE로 확장 가능

4-7. 장단점 정리

기법 장점 단점 언제
Full Factorial 교호작용 완전 분리, 해석 명확, 근거로 쓰기 좋음 변수 늘면 폭발 변수 ≤ 6~8, 스크리닝 근거를 확실히 남길 때

5. 근사모델 (대리모델)

5-1. 개념

DOE로 얻은 소수의 (설계점, 응답) 쌍으로 응답면 함수 ŷ(x) 를 만들어, 이후 최적화에서 솔버 대신 사용합니다.

실제:   x → [FEA 솔버, 4초] → y
대리:   x → [ŷ(x), 0.0001초] → ŷ ≈ y

GA처럼 수천 번 평가가 필요한 알고리즘은 대리모델 없이는 불가능합니다.

5-2. 기법별 원리와 수식

① LSR (Least Squares Regression) — 다항식 회귀

ŷ(x) = β₀ + Σ βᵢxᵢ + Σ βᵢᵢxᵢ² + Σ βᵢⱼxᵢxⱼ

계수 β는 잔차제곱합을 최소화해 구합니다: β = (XᵀX)⁻¹Xᵀy

  • [축A] 결정론적
  • 장점: 가장 단순, 계수가 곧 변수 중요도(해석 가능), 외삽이 안정적, 매우 빠름
  • 단점: 다봉·강한 비선형 표현 불가. 차수를 올리면 진동(Runge 현상)

② MLSM (Moving Least Squares) — 국소 가중 회귀

예측점 x 근처의 데이터에 더 큰 가중치를 줘서 국소적으로 회귀합니다.

min Σ w(‖x − xᵢ‖) · [ŷ(xᵢ) − yᵢ]²

가중함수 w는 거리가 멀수록 0으로 감소 (가우시안 등).

  • [축A] 결정론적
  • 장점: LSR보다 비선형 대응력↑, 노이즈에 강함(스무딩 효과)
  • 단점: 계수 해석 불가, 데이터 범위 밖에서 불안정

③ HK (HyperKriging) — 가우시안 확률과정

ŷ(x) = f(x)ᵀβ + Z(x)
        └회귀항┘  └확률과정항┘

Z(x): 평균 0, 공분산 Cov[Z(xᵢ), Z(xⱼ)] = σ² R(xᵢ, xⱼ) 인 가우시안 과정
R: 상관함수 (예: 가우시안  R = exp(−Σθₖ|xᵢₖ − xⱼₖ|²) )
  • [축A] 학습은 결정론적(재현됨) / [축B] 모델 자체가 확률적 해석을 가짐
  • ★ 핵심 특징: 예측값과 함께 예측 분산(불확실성) 을 내놓습니다. "이 지점은 데이터가 적어서 예측이 불확실하다"를 정량화할 수 있습니다.
  • 장점: 신뢰구간 제공 → 적응 샘플링(EGO, Efficient Global Optimization) 가능, 비선형 매우 강함, 학습점을 정확히 통과
  • 단점: 학습 비용 큼(상관행렬 역행렬), 데이터 많으면 느려짐, θ 최적화가 까다로움

"Kriging이 확률적"이라는 말의 정확한 뜻: 응답을 확률과정으로 모델링해서 분산을 함께 준다는 뜻이지, 알고리즘이 랜덤하다는 뜻이 아닙니다.

④ RBF (Radial Basis Function) — 방사기저함수

ŷ(x) = Σᵢ wᵢ · φ(‖x − xᵢ‖)

각 학습점을 중심으로 하는 기저함수 φ의 가중합. 가중치 w는 학습점을 정확히 통과하도록(보간) 선형계를 풀어 구합니다.

φ 종류 | 형태 | 수식 | 특징 | |---|---|---| | Gaussian | exp(−(εr)²) | 매끄러움, 전역 영향 | | Multiquadric | √(1 + (εr)²) | 전통적, 안정 | | Thin plate spline | r² ln r | 2D 보간에 자주 | | CS21 (Compact Support) | 유한 반경 밖에서 0 | HyperStudy 기본값. 희소행렬 → 빠름 |

  • [축A] 결정론적
  • 장점: 학습점을 정확히 통과, 비선형 매우 강함, 빠름, 고차원 OK
  • 단점: 학습점 사이·바깥에서 과적합·진동 위험, 신뢰구간 없음

HS-3000/4000이 쓰는 설정 (실측): RbfType=CS21, AugmentedFunction=0, RelaxationParam=1, FeatureReduction=Off, MaxPoints=2000, 학습 데이터 = MELS 31런

⑤ FAST — 자동 선택

여러 fit을 자동으로 만들어 교차검증 성능이 가장 좋은 것을 고릅니다. 편하지만 어떤 게 선택됐는지 반드시 확인해야 합니다.

5-3. 성능 평가 지표

지표 수식 의미 판정
R² 1 − SSE/SST 학습 데이터 설명력 1에 가까울수록 좋음. 단 과적합이면 1이어도 예측은 엉망
R² (cross-validation) 일부 빼고 학습→예측 진짜 예측력 ★ 이게 핵심 지표

교차검증(Cross-Validation)이 왜 중요한가 RBF처럼 학습점을 정확히 통과하는 모델은 학습 R²가 항상 1.0입니다. 그런데 학습점 사이에서는 엉뚱한 값을 낼 수 있습니다. 데이터 일부를 빼고 학습한 뒤 그 점을 맞히는지 봐야 진짜 실력을 압니다.

5-4. ★ 실무에서 가장 중요한 교훈

대리모델의 R²가 아무리 좋아도, 최적화는 응답면의 "가장 극단"을 찾아가기 때문에 근사 오차가 가장 크게 드러나는 지점에서 답이 나옵니다.

Arm 모델에서 RBF(MELS 31런) 위에서 최적화한 뒤, 그 최적해를 실제 솔버로 재해석한 결과:

최적화 기법 대리모델 예측 Max_Disp 실제 해석값 제약(≤1.5)
ARSM 1.5067 1.5049 만족
GRSM 1.5041 1.5342 위반
SQP 1.5000 1.5325 위반
GA 1.5072 1.5481 위반

Volume 오차도 +0.02% ~ +1.41%로 기법마다 크게 달랐습니다.

왜 SQP가 가장 위험한가: SQP는 제약 경계를 정밀하게 추종해 정확히 1.50000에 수렴합니다. 여유가 0이니 근사 오차 약 2%가 그대로 위반이 됩니다. 반면 ARSM은 1.5067에서 멈춰 근사 오차를 흡수했습니다.

결론: 대리모델 위에서 제약 경계에 정밀하게 붙는 기법일수록 실제 검증에서 제약을 위반할 위험이 큽니다. 대리모델 기반 최적해는 반드시 실솔버로 검증할 것.

6. 민감도 분석

6-1. 국소 민감도 (Local Sensitivity)

한 점에서의 편미분:

Sᵢ = ∂f/∂xᵢ  (또는 정규화:  (xᵢ/f)·∂f/∂xᵢ )
  • [축A] 결정론적
  • 계산이 쌈. 하지만 그 점 근처에서만 유효
  • gradient 기반 최적화(SQP, MFD)가 내부적으로 계속 사용
  • FEA에서는 해석적 미분이 어려워 유한차분으로 근사: ∂f/∂xᵢ ≈ [f(x + Δeᵢ) − f(x)] / Δ → 변수 n개면 매 반복마다 n+1회 해석 필요. SQP가 비싼 이유. → 또한 솔버 노이즈에 매우 취약 (Δ가 작으면 노이즈가 미분값을 지배)

6-2. 전역 민감도 — 회귀 기반

DOE 데이터 전체에 회귀를 적합해 표준화 회귀계수를 봅니다.

표준화 계수 βᵢ* = βᵢ · (σ_xᵢ / σ_y)
기여도 [%] = |Eᵢ| / Σ|Eⱼ| × 100

Pareto plot(막대그래프)으로 표시하는 게 일반적입니다.

  • [축A] 결정론적
  • 선형 가정. 계산 쉬움. HyperStudy의 Linear Effects가 이것

6-3. 전역 민감도 — 분산 기반 (Sobol 지수)

출력의 분산을 변수별 기여로 분해합니다.

V(y) = Σ Vᵢ + Σ Vᵢⱼ + ... + V₁₂...ₙ

1차 지수:  Sᵢ = Vᵢ / V(y)            ← xᵢ 단독 기여
총 지수:   S_Tᵢ = 1 − V₋ᵢ / V(y)     ← xᵢ가 관여한 모든 기여(교호작용 포함)
  • [축B] 확률론적 — 입력을 확률변수로 보고 몬테카를로 샘플링
  • 장점: 비선형·교호작용까지 정확히 잡음. 모델 형태 가정 불필요
  • 단점: 샘플이 매우 많이 필요 (보통 수천~수만). 대리모델 위에서 돌리는 게 보통
  • S_Tᵢ − Sᵢ 가 크면 그 변수는 교호작용으로 작용한다는 뜻

6-4. CoP 기반 (OptiSLang MOP)

대리모델의 예측력(CoP)을 변수별로 분해해 중요도를 산출합니다. OptiSLang의 대표 기능이며, "어떤 변수를 빼면 예측력이 얼마나 떨어지는가"로 해석합니다.

7. 최적화 알고리즘

7-1. 큰 분류

최적화 알고리즘
├── ① 경사 기반 (Gradient-based)
│      미분정보 사용. 빠르지만 국소최적해 위험, 노이즈 취약
│      → SQP, MFD, Steepest Descent, Newton
│
├── ② 무경사 / 메타휴리스틱 (Gradient-free)
│      미분 불필요. 전역탐색 강함, 평가 횟수 매우 많음
│      → GA, MOGA, PSO, Simulated Annealing
│
└── ③ 반응면 기반 (Surrogate-assisted / Adaptive)
       근사모델을 반복 갱신하며 탐색. 적은 평가로 좋은 성능
       → ARSM, GRSM

7-2. 경사 기반 알고리즘

Steepest Descent (최급강하법)

x_{k+1} = x_k − α ∇f(x_k)

가장 단순. 수렴이 느리고 좁은 골짜기에서 지그재그.

Newton's Method

x_{k+1} = x_k − H⁻¹ ∇f(x_k)      H = 헤시안(2차 미분 행렬)

2차 정보를 써서 훨씬 빠름. 하지만 헤시안 계산·저장 비용이 큼. Quasi-Newton(BFGS) 은 헤시안을 근사로 갱신해 이 문제를 완화합니다.

★ SQP (Sequential Quadratic Programming)

매 반복마다 목적함수를 2차, 제약을 1차로 근사한 QP 부문제를 풀어 이동 방향 d를 얻습니다.

min_d   ½ dᵀ B_k d + ∇f(x_k)ᵀ d
s.t.    ∇gⱼ(x_k)ᵀ d + gⱼ(x_k) ≤ 0
        ∇hₖ(x_k)ᵀ d + hₖ(x_k) = 0

B_k = 라그랑주 함수 헤시안의 근사 (BFGS로 갱신)
x_{k+1} = x_k + α d          α는 line search로 결정
  • [축A] 결정론적 — 같은 시작점이면 완전히 재현됨
  • 제약 있는 비선형 문제의 사실상 표준. HyperStudy/OptiSLang/PIAnO 모두 지원
  • 장점: 국소 최적해를 정밀하게 찾음. 제약을 정확히 만족(모델 기준)
  • 단점:
  • 유한차분 gradient 때문에 평가 횟수가 많음 (실측 191~209회)
  • 시작점에 민감 — 비볼록 문제에서 다른 국소해로 감
  • 솔버 노이즈에 취약 — 1e-5 노이즈가 유한차분 미분을 오염시켜 탐색 경로가 갈림
  • 대리모델 위에서는 제약 경계에 정확히 붙어 검증 시 위반 위험

MFD (Method of Feasible Directions)

현재 실행가능한 점에서, ① 목적함수를 개선하면서 ② 실행가능영역을 벗어나지 않는 방향(usable-feasible direction)만 골라 이동합니다.

d 를 찾되:   ∇f ᵀd < 0           (목적함수 개선)
             ∇gⱼᵀd ≤ 0  (active 제약에 대해)   (실행가능 유지)
  • [축A] 결정론적
  • 장점: 항상 실행가능영역 안에 머묾. 제약이 많은 구조최적화에 전통적으로 강함. SQP보다 훨씬 적은 평가로 비슷한 품질 (실측 48~62회 vs 191~209회)
  • 단점: 자료가 적고 튜토리얼에 잘 안 나옴. 초기점이 실행가능해야 함

7-3. 메타휴리스틱

★ GA (Genetic Algorithm)

생물 진화를 모사합니다.

1. 초기 개체군 무작위 생성 (예: 105개)
2. 반복:
   a. 평가     — 각 개체의 적합도 계산
   b. 선택     — 좋은 개체를 확률적으로 뽑음 (룰렛휠, 토너먼트)
   c. 교차     — 두 부모의 유전자를 섞어 자식 생성 (Crossover)
   d. 변이     — 낮은 확률로 유전자를 무작위 변경 (Mutation, 보통 1%)
   e. 엘리트 보존 — 최고 개체 일부는 그대로 다음 세대로
3. 수렴 또는 최대 세대 도달 시 종료
  • [축A] 확률적 — 초기 개체군·교차점·변이가 전부 난수. 매번 다른 답
  • 장점: 미분 불필요, 이산변수 가능, 비볼록·다봉에 강함, 전역탐색, 병렬화 쉬움
  • 단점: 평가 횟수 수천 회 → 실솔버로는 비현실적. 반드시 대리모델 위에서. 수렴 판정이 애매

HyperStudy 실측 파라미터: GAPOPS=105(개체군), GAMUTR=0.01(변이율), GAELIT=10(엘리트), GATOUR=2(토너먼트 크기), 총 2,913회 평가

PSO (Particle Swarm Optimization)

새떼/물고기떼를 모사. 각 입자가 자기 최고기록과 집단 최고기록을 향해 이동.

v_{k+1} = ω·v_k + c₁r₁(p_best − x_k) + c₂r₂(g_best − x_k)
x_{k+1} = x_k + v_{k+1}

GA와 용도 비슷, 구현이 단순. [축A] 확률적

Simulated Annealing (담금질 모사)

금속 열처리를 모사. 초반엔 나쁜 해도 확률 exp(−Δf/T) 로 수용해 국소해를 탈출하고, 온도 T를 점차 낮춰 수렴시킵니다. 이산 최적화에 유용. [축A] 확률적

★ ARSM (Adaptive Response Surface Method)

2. 반복:

  • 단점: 국소 반응면 기반이라 전역최적해를 놓칠 수 있음. 실측에서 목적값이 다른 기법보다 명확히 나빴음 (1,702,450 vs GRSM 1,645,450)

8. 다목적 최적화

8-1. 왜 필요한가

실제 설계는 목표가 여러 개고 서로 충돌합니다. "무게도 줄이고 강성도 높이고" — 둘 다 최고인 설계는 보통 없습니다.

8-2. 지배(Dominance)와 파레토 최적

설계 A가 설계 B를 지배(dominate) 한다:

모든 목적에서 A가 B보다 나쁘지 않고,
적어도 하나의 목적에서 A가 B보다 확실히 좋다

파레토 최적해: 어떤 다른 해에도 지배당하지 않는 해. 이들의 집합이 파레토 프론트(Pareto Front) 입니다.

  Max_Disp ↑
      │  ●  ← 지배당함 (둘 다 나쁨)
      │
      │ ○
      │   ○           ○ = 파레토 최적해
      │     ○           서로 우열을 가릴 수 없음
      │        ○  ○     → 설계자가 취향/요구에 따라 선택
      │             ○
      └──────────────────→ Volume

8-3. 기법

기법 방식 비고
가중합법 min w₁f₁ + w₂f₂ 간단하지만 가중치를 바꿔가며 여러 번 풀어야 함. 비볼록 프론트는 못 찾음
ε-제약법 f₁ 최소화, f₂ ≤ ε 제약 ε를 바꿔가며 반복
MOGA / NSGA-II GA를 다목적으로 확장. 비지배 정렬 + 밀집도 유지 한 번에 프론트 전체를 얻음. 평가 횟수 매우 많음
GRSM (다목적 모드) 반응면 기반 MOGA보다 훨씬 적은 평가. 대리모델 없으면 이쪽 권장
  • [축A] MOGA/NSGA-II는 확률적, 가중합·ε-제약은 내부 알고리즘에 따름

HS-4425가 다루는 주제입니다. 튜토리얼 안내: "Fit이 없으면 MOO는 평가가 많이 필요하므로 MOGA보다 GRSM이 효율적"

9. 신뢰성 · 강건설계 (RBDO)

[축B] 확률론적 설계의 영역입니다.

9-1. 왜 필요한가

DDO의 최적해는 §1-2(KKT 상보조건)에서 봤듯 거의 항상 제약 경계 위에 놓입니다. 여유가 0이라는 뜻입니다.

      제약 경계 (Max_Disp = 1.5)
           │
   확률밀도 │
      ╱╲   │
     ╱  ╲  │        실제 생산품의 분포
    ╱    ╲ │
   ╱      ╲│
  ╱        ╳────── 이 오른쪽 절반이 전부 파손!
 ╱         │╲
───────────┼──────────→ Max_Disp
          1.5

최적해가 정확히 경계에 있으면, 제조 산포가 대칭이라 가정할 때 약 50%가 제약을 위반합니다. 이것이 RBDO의 존재 이유입니다.

9-2. 확률 기초

개념 수식 설명
정규분포 X ~ N(μ, σ²) 평균 μ, 분산 σ²
표준화 Z = (X − μ)/σ 표준정규 N(0,1)로 변환
한계상태함수 g(x) g < 0 이면 파손, g > 0 이면 안전
파손확률 P_f = P[g(X) ≤ 0]
신뢰도 R = 1 − P_f

9-3. 신뢰도 지수 β

P_f = Φ(−β)        Φ = 표준정규 누적분포함수
β = −Φ⁻¹(P_f)
목표 신뢰도 파손확률 P_f β
90% 1e-1 1.28
95% 5e-2 1.645
99% 1e-2 2.33
99.9% 1e-3 3.09
99.99% 1e-4 3.72
99.9999% (6σ) 1e-6 4.75

9-4. MPP (Most Probable Point, 최확점)

표준정규공간(U-space)에서 한계상태면 위의 점 중 원점에 가장 가까운 점입니다.

MPP:  u* = argmin ‖u‖   subject to  G(u) = 0
β = ‖u*‖

왜 원점에서 가장 가까운 점인가: 표준정규공간에서 확률밀도는 원점에서 최대이고 거리에 따라 지수적으로 감소합니다. 따라서 파손이 일어난다면 거기서 일어날 확률이 가장 높습니다. 그래서 "최확점".

   u₂ ↑        한계상태면 G(u)=0
      │       ╱
      │      ╱
      │     ● ← MPP (u*)
      │    ╱ ╲
      │   ╱   ╲ β = ‖u*‖
      │  ╱     ╲
      │ ╱       ╲
   ───┼─────────●───────→ u₁
      │ 원점(평균)

RBDO 검증에서 MPP를 확인하는 이유: 어떤 변수 조합에서 파손이 가장 잘 일어나는지 알려주므로, 그 방향의 공차를 조이는 등 실질적 대책을 세울 수 있습니다.

9-5. FORM / SORM

기법 한계상태면 근사 정확도 비용
FORM (First Order Reliability Method) MPP에서 접평면(1차) 보통 낮음
SORM (Second Order) MPP에서 2차 곡면 높음 중간
Monte Carlo 근사 없이 직접 샘플링 정확 매우 높음 (P_f=1e-4면 10⁶회 필요)

9-6. RIA vs PMA — RBDO를 푸는 두 방식

방식 정식 푸는 문제 특징
RIA (Reliability Index Approach) 신뢰도 지수 접근 현재 설계의 β를 계산 → 목표와 비교 직관적. 수렴 불안정할 수 있음
PMA (Performance Measure Approach) 성능 척도 접근 목표 β에 해당하는 성능값을 계산 수렴 안정적. 실무 선호

9-7. SORA (Sequential Optimization & Reliability Assessment)

신뢰성 해석과 최적화를 번갈아 수행해 계산량을 크게 줄입니다.

반복:
  1. 결정론적 최적화를 푼다 (제약을 안전측으로 이동시킨 상태로)
  2. 그 해에서 신뢰성 해석(MPP 탐색)을 한다
  3. MPP 정보로 제약 이동량(shift)을 갱신한다
  4. 수렴할 때까지 1~3 반복
  • [축A] 결정론적 (내부 최적화가 결정론적이면)
  • [축B] RBDO
  • 장점: 중첩 루프(nested loop)보다 훨씬 빠름. HyperStudy가 제공
  • 단점: 설정 복잡. 분포 정보가 필요

10-1. 왜 반드시 해야 하나

   - 목적함수:  예측값 vs 실측값,  오차율 = (예측−실측)/실측 × 100
   - 제약:      실측값이 제약을 실제로 만족하는가
4. 제약 위반이면 그 최적해는 채택 불가

11-4. 결론

  1. GRSM이 비용 대비 최고 — 50회로 최고 품질
  2. MFD가 숨은 가성비 — 48~62회로 SQP(191~209회)와 동급. 튜토리얼이 안 다룸
  3. ARSM은 가장 싸지만(11~14회) 품질이 명확히 떨어짐 — 빠른 1차 탐색용. 다만 대리모델 위에서는 유일하게 검증을 통과
  4. SQP는 4배 비싸고 품질 이득 없음 (이 문제에서는)
  5. 대리모델 기반 최적해는 ARSM 외에 전부 제약 위반 — 반드시 검증할 것

12. 한 장 요약 — 언제 뭘 쓰나

■ 변수 20개 이상, 뭐가 중요한지 모름
    → Plackett-Burman 또는 Fractional Factorial III 로 스크리닝

■ 변수 6~10개, 교호작용까지 확실히 보고 싶음
    → Full Factorial (단, 2ⁿ 폭증 주의)

■ 대리모델을 만들고 싶음
    → MELS 30~50런 → RBF 또는 HK 학습 → 교차검증 R² 확인

■ 빠르게 대략적인 최적해만
    → ARSM (10~15회) — 재현성 100%, 제약 여유 있게 수렴

■ 품질 좋은 최적해를 합리적 비용으로        ★ 이번 실습 1위
    → GRSM (50회) — 단, 확률적이라 2~3회 돌려 확인 권장

■ 제약이 많은 구조 문제, 비용도 아껴야
    → MFD (48~62회)

■ 정밀한 국소 최적해가 꼭 필요
    → SQP — 단 평가 200회, 시작점 민감, 노이즈 취약

■ 이산변수 / 다봉 / 다목적
    → GA · MOGA — 반드시 대리모델 위에서 (수천 회 평가)

■ 다목적인데 대리모델이 없음
    → GRSM 다목적 모드 (MOGA보다 훨씬 경제적)

■ 산포·신뢰성을 고려해야
    → SORA (RBDO) — [축B] 확률론적 설계

■ 성능 편차 자체를 줄여야
    → Robust Design (SRO)
